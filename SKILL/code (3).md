# Skill: VLM 多模态调用工程规范

## 触发条件
代码涉及调用视觉大模型(发送图片/音频/视频)。

## 规则
1. 图片发送前必须压缩： QImage → scaled(2048) → JPEG quality 85 → base64。禁止直传原图。
2. 多轮对话必须做历史瘦身：仅保留最近 N 条消息中的图片，旧图降级为 "[图片消息]" 占位文本。
3. 流式渲染必须节流：QTimer 80ms 批量刷新，禁止每 chunk 触发 setMarkdown。
4. 文本追加用「累积 buffer + 全量 setMarkdown」，禁止 append()（会重复旧内容）。
5. API client 在 Worker 线程内创建，禁止跨线程共享。
6. 忙时按钮变"停止"，worker.stop() 优雅取消而非强杀。
7. 视频先抽帧(均匀 8 帧)再喂模型，禁止逐帧全量发送。
8. 相同图片内容 hash 缓存响应，省钱防重复请求。
