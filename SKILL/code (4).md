# Skill: 输出前自检

## 触发条件
生成完整代码文件后、输出前，静默执行（不输出过程，只修结果）。

## 自检项（按序）
1. import 完整性：代码中用到的每个符号都有对应 import？
2. API 真实性：每个第三方 API 调用，我是否 100% 确定其签名？不确定 → 改为保守写法或显式标注"此 API 以 X 版本文档为准"
3. 生命周期：每个创建的对象是否被正确持有/释放？线程是否可停止？
4. 边界：空输入、超长输入、None、异常路径是否处理？
5. 伪代码扫描：禁止 ... 、pass # TODO、省略的 for 循环出现在交付代码中

## 诚实原则
不确定的库版本行为，宁可写"版本差异提示"也不编造参数。承认局限比幻觉代码价值高 10 倍。
